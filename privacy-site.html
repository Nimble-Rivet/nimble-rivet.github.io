Эта страница описывает сайт Nimble Rivet и обращения по электронной почте. Для каждого приложения опубликована отдельная политика с учётом его функций.

Посещение сайта

Сайт состоит из статических страниц. Мы не подключаем рекламные системы, счётчики аналитики, сторонние виджеты или формы сбора данных. Сайт не устанавливает cookies и не записывает сведения в локальное хранилище браузера. Изображения и шрифты загружаются с того же сайта.

Сайт размещён на GitHub Pages. При посещении GitHub получает технические сведения, необходимые для доставки страниц; в частности, GitHub сообщает, что сохраняет IP-адрес посетителя для обеспечения безопасности. Эти сведения обрабатывает GitHub по собственной политике, а не встроенный счётчик Nimble Rivet. Подробнее: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages и https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

Электронная почта

Ссылка на адрес поддержки открывает ваше почтовое приложение. Пока вы не отправите письмо, сайт не передаёт нам его текст. При отправке мы получаем адрес отправителя, текст и приложенные вами файлы. Почтовые сервисы отправителя и получателя также обрабатывают письмо по своим правилам. Адрес поддержки Nimble Rivet обслуживается Gmail: https://policies.google.com/privacy.

Мы используем сведения из обращения для ответа, разбора ошибки и продолжения переписки по вашему вопросу. Отправляйте только необходимые данные. Обычно достаточно названия приложения, модели устройства, версии Android и описания ситуации; резервные копии или личные сведения добавляйте только при необходимости.

Хранение и удаление обращений

Переписка хранится столько, сколько необходимо для рассмотрения обращения и связанных с ним вопросов. Чтобы запросить удаление сведений, которые вы отправили в поддержку, напишите на nimblerivet@gmail.com с адреса, использованного для обращения. Возможности и сроки удаления из резервных копий почтового сервиса определяются его правилами.

Данные приложений

Способы хранения, резервирования и удаления данных различаются между приложениями. Пользуйтесь политикой нужного приложения в разделе «Конфиденциальность». Посещение этого сайта само по себе не предоставляет Nimble Rivet доступ к содержимому приложений на вашем устройстве.

Изменения

При изменении работы сайта или поддержки мы обновим эту страницу и дату в её начале.
