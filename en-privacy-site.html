This page describes the Nimble Rivet website and email support. Each app has its own privacy policy covering its features.

Visiting the website

This website consists of static pages. We do not add advertising systems, analytics trackers, third-party widgets or data collection forms. The site does not set cookies or write to browser local storage. Images and fonts are served from this same site.

The website is hosted on GitHub Pages. GitHub receives technical information needed to serve pages; in particular, GitHub states that it logs and stores visitor IP addresses for security purposes. GitHub processes this information under its own policy; this is not a Nimble Rivet analytics tracker. See https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages and https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

Email

The support link opens your email application. The website does not send us a message before you choose to send it. When you send an email, we receive your sender address, message and attachments. The sender's and recipient's email providers also process the message under their own rules. Nimble Rivet's support address uses Gmail: https://policies.google.com/privacy.

We use the information in your request to reply, investigate a reported issue and continue the conversation about it. Send only what is necessary. Usually the app name, device model, Android version and a description are enough; include backups or personal information only if needed.

Retention and deletion of support requests

We retain correspondence for as long as needed to handle your request and related questions. To request deletion of information you sent to support, email nimblerivet@gmail.com from the address used for your request. Removal from the email provider's backups and its timing are subject to that provider's rules.

App data

Storage, backup and deletion differ between apps. Read the relevant app policy in the Privacy section. Visiting this website does not by itself give Nimble Rivet access to app contents on your device.

Changes

When the website or support practices change, we will update this page and its date.
